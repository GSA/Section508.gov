<h2 style="line-height:1.2;">Did you know that the text inside a form field isn't necessarily a label?</h2>

You've probably seen forms that look like this:

    <div class="font-mono-3xs margin-x-auto auto" style="max-width: 90%; text-align: center;"><span id="figure-figure number"><strong>Figure figure number.</strong> Caption text.</span></div>
</div>

The words inside the field are called placeholder text. Placeholder text can provide a hint or example, but it shouldn't replace a clear label that identifies the purpose of the field.

## What's the Problem?
Placeholder text often disappears as soon as someone begins typing.

Imagine starting to complete a long form and then being interrupted. When you return, the text you entered may still be there, but the instructions that appeared inside the fields are gone.

Now you have to remember what each field was asking for.
This can create additional barriers for people with cognitive disabilities, memory limitations, or low vision. Placeholder text may also create problems when it isn't properly communicated to assistive technology.

## Give Every Field a Clear Label
Instead of putting the only description inside the field:

    <div class="font-mono-3xs margin-x-auto auto" style="max-width: 90%; text-align: center;"><span id="figure-2"><strong>Figure 2.</strong> Caption text.</span></div>
</div>

Provide a visible label that remains available:

<div class="tablet:grid-col" style="margin: auto; max-width: 100%; text-align: center; padding: 10px 0px">
    <div class="margin-top-1"><img src="{{site.baseurl}}/assets/images/byte-024-figure-3.jpg" alt="Form input field with the label 'Email Address' and no placeholder text inside the field." aria-describedby="figure-3" class="border-2px border-base-light shadow-2 padding-1"></div>

</div>

The label identifies what information belongs in the field before, during, and after the user enters information.

## Use Placeholder Text for Hints, Not Labels
Placeholder text isn't always bad.

It can be useful for providing a short example or hint when additional information will help the user complete the field.

For example:

<div class="tablet:grid-col" style="margin: auto; max-width: 100%; text-align: center; padding: 10px 0px">
    <div class="margin-top-1"><img src="{{site.baseurl}}/assets/images/byte-024-figure-4.jpg" alt="Form input field with the label 'Email Address' and placeholder text 'user.name@example.gov' inside the field." aria-describedby="figure-4" class="border-2px border-base-light shadow-2 padding-1"></div>
    <div class="font-mono-3xs margin-x-auto auto" style="max-width: 90%; text-align: center;"><span id="figure-4"><strong>Figure 4.</strong> Caption text.</span></div>
</div>

In this example, **Email address** is the label. The placeholder, user.name@example.gov, provides an example of the information the user should enter.

If instructions are important for successfully completing the field, however, don't rely on placeholder text alone. Provide clear instructions where they remain available to the user.

If you answer no to any of these questions, you may have identified an accessibility issue.

## Key Takeaways
Placeholder text can provide a useful hint or example, but it shouldn't replace a form field's label.

* Keep labels visible. Use placeholder text only for supplemental information.

A simple test can help: enter something into the field. If you can no longer tell what the field is asking for, the placeholder was probably doing a job that belongs to the label.
